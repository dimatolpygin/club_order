# Запрещается:
- смайлы
- типичные градиенты фиолетовый (сразу понятно сайт - навайбкожен)
- отсутствие завершенной логики: нет кнопки выйти,войти,смена пароля от админки,в разделах админки есть не работающие кнопки или 
ui|ux функционал не полный
- сырые данные рендерить по типу переменных каких то, админ это обычный человек у него нет понимания IT вещей(все адаптировано и переведено на человечный)



# База 
- кастомные иконки вместо смайлов
- цвета используйте черный + белый; синие + зеленые (для показателей на дашборде)
- для графиков дашборды (внимательно по осям Х и У чтобы не было артефактов)
