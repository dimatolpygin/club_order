# Выкат веб-админки в прод (этап 30)

Прод-сервер: `163.5.153.150` (`/opt/club_bot`), домен `admin.agat-key.ru`
(A-запись → 163.5.153.150, опубликована в nic.ru 2026-06-26).

Веб-админка — сервис `admin` в `docker-compose.yml`: uvicorn на `127.0.0.1:8011`,
наружу проксирует системный Nginx с https (Let's Encrypt). Логин/секрет — из `.env`
(`ADMIN_WEB_*`). Миграции применяет сервис `bot` (общая БД, схема `club_bot`).

## Разовая настройка прода

1. **`.env`** (на сервере, gitignored — авто-деплой его не трогает): дописать
   ```
   ADMIN_WEB_SECRET=<openssl rand -hex 32>
   ADMIN_WEB_LOGIN=admin
   ADMIN_WEB_PASSWORD=<надёжный пароль>
   ```
   Секрет менять нельзя после старта (разлогинит сессии); пароль после первого входа
   меняется через UI (`/password`). Первый админ сеется при старте контейнера, если
   таблица `admin_users` пуста.

2. **Деплой кода** — мерж `dev→master` + push: GitHub Actions делает
   `git reset --hard origin/master` + `docker compose up -d --build` → применяются
   миграции 0011–0023, пересобирается бот, поднимается контейнер `admin`.

3. **Nginx + https** (один раз):
   ```bash
   apt-get update && apt-get install -y nginx certbot python3-certbot-nginx
   cp deploy/nginx/admin.agat-key.ru.conf /etc/nginx/sites-available/admin.agat-key.ru
   ln -sf /etc/nginx/sites-available/admin.agat-key.ru /etc/nginx/sites-enabled/
   rm -f /etc/nginx/sites-enabled/default
   nginx -t && systemctl reload nginx
   certbot --nginx -d admin.agat-key.ru --non-interactive --agree-tos -m <email>
   ```
   certbot допишет 443-блок + редирект 80→443 и поставит авто-обновление сертификата.

## Проверка

- `curl -fsS http://127.0.0.1:8011/healthz` на сервере → `{"status":"ok"}`.
- `https://admin.agat-key.ru` открывается с валидным сертификатом, вход по логину/паролю.
