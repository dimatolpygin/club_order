# Навигация экранов бота — черновик-источник для Этапа 22

> Снято с кода 2026-06-25 (этап 19). Цель документа — зафиксировать дерево экранов
> бота, источник текста каждого экрана и его кнопки, чтобы спроектировать веб-редактор
> экранов (Этап 22: правка текста экрана + подписей/видимости кнопок по разделам).
> Это **черновик**: при взятии Этапа 22 в работу сверить с актуальным кодом.

Обозначения: `screen:*` — имя экрана в `fsm_states` (пишется через `repo.set_fsm_state`).
Текст — константа/функция в `src/texts.py`. Кнопки — клавиатура из `src/keyboards.py`
или (для меню) реестр `src/services/menu.py`.

## Легенда «редактируемость»
- **T** — текст экрана осмысленно редактировать в админке (статичный копирайт).
- **B** — подписи/видимость кнопок (часть уже в Этапе 19 для меню).
- **dyn** — экран собирается динамически (цены/даты/списки) — редактируется только
  шаблон/обрамление, не данные.

## Заметки для проектирования Этапа 22
- **Минимальный полезный объём**: редактирование статичных инфо-экранов (раздел 2) +
  служебных текстов-заглушек (пусто/ошибки/распродано). Динамические экраны (цены,
  даты, списки) трогать рискованно — там данные, а не копирайт.
- Хранить переопределения текстов отдельной таблицей (ключ экрана → текст), дефолты —
  в `texts.py`; бот рендерит с fallback (как `menu_buttons` для кнопок этапа 19).
- Объединить с этапом 19: на странице экрана — и текст, и его кнопки (подпись/видимость).
- Плейсхолдеры в редактируемом тексте (если останутся динамические вставки) — описать
  явный белый список, иначе правка сломает форматирование/подстановку.
